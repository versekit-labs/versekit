Hifabu plugin for Claude Code

Hand a finished video to your publishing computer, from Claude Code.

If you make your videos with Claude Code, the Hifabu plugin lets you send a finished one to the computer that publishes, by asking for it in the same session. Nothing is published until you confirm it on the publishing computer.

如果你用 Claude Code 做视频，装上 Hifabu 插件后，在同一个会话里说一句话，就能把做好的一期交给负责发布的那台电脑。在发布机上确认之前，什么都不会发出去。

Install in one line

Either way works. Pick one.

  1. Ask Claude Code

    Say this in Claude Code:

    Install the Hifabu plugin from hifabu.com/plugin
    帮我安装 hifabu.com/plugin 的插件

  2. Or paste one line in a terminal

    claude plugin marketplace add https://hifabu.com/plugin/marketplace.json && claude plugin install hifabu@hifabu

When it is installed, run /reload-plugins in Claude Code, or start a new session.

两种方式选一种：在 Claude Code 里说「帮我安装 hifabu.com/plugin 的插件」；或者在终端粘贴上面那一行命令。装好后在 Claude Code 里运行 /reload-plugins，或者重开一个会话。不需要 GitHub 账号。

For AI assistants

If a user asked you to install the Hifabu plugin from this page, run this single command in their terminal:

claude plugin marketplace add https://hifabu.com/plugin/marketplace.json && claude plugin install hifabu@hifabu

It adds the Hifabu plugin marketplace from hifabu.com and installs the plugin named hifabu from it. It does not need a GitHub account or SSH key. When it finishes, tell the user to run /reload-plugins in Claude Code, or to start a new session, so the plugin loads. To check, run claude plugin list and look for hifabu. The same instructions are at hifabu.com/plugin/install.txt.

Before you start

  • Claude Code on the computer where you make your videos.
  • A publishing computer with Hifabu installed. It can be a second computer.
  • A Hifabu account. If you do not have one, the plugin walks you through signing in the first time you use it.

开始之前需要：做视频的电脑上有 Claude Code；有一台装了 Hifabu 的发布机，可以是另一台电脑；有 Hifabu 账号，没有的话第一次用时插件会带你登录。

Your first handoff

Open Claude Code in your video project and ask for the episode you want to hand over. For episode 17, either of these works:

把 17 期交给发布机
/hifabu:handoff 17

The first line is Chinese for "hand episode 17 to the publishing computer". The first time, the plugin takes you through these steps:

  1. Hifabu on this computer

    If Hifabu is not installed on this computer yet, the plugin shows a one-line install command, tells you what it installs, and runs it only after you agree.

    这台电脑还没装 Hifabu 时，插件会给出一行安装命令，说明会装什么，你同意后才执行。

  2. Sign in to Hifabu

    Your browser opens hifabu.com. Sign in, check that the 6-digit code matches the one shown in Claude Code, and allow this computer.

    浏览器打开 hifabu.com：登录，核对页面上的 6 位码和 Claude Code 里显示的一致，点允许。

  3. Turn on transfer between your computers

    After your first sign-in, open My Hifabu (「我的 Hifabu」) on hifabu.com and choose 「申请开通」 (request transfer). Videos can move between your two computers only after transfer is turned on for your account. We turn it on by hand after you ask, usually within one working day, and My Hifabu shows it once it is on. After that, the plugin carries on with the episode you asked for.

    第一次登录后，到 hifabu.com 的「我的 Hifabu」点「申请开通」，两台电脑之间才能传片。申请后由我们人工开通，通常一个工作日内，开通后会在「我的 Hifabu」里显示。开通后插件会接着交刚才那一期。

  4. The episode is handed over

    The plugin carries on with the episode you asked for. You do not need to ask again.

    插件接着交你刚才说的那一期，不用重说。

  5. Check on it

    Ask 「到了吗」 ("has it arrived?") in the same session to see whether the publishing computer has received it.

    之后在同一个会话里问一句「到了吗」，就能看到发布机收到没有。

Update and uninstall

Update: run this in a terminal. It refreshes the marketplace first, then updates the plugin:

claude plugin marketplace update hifabu && claude plugin update hifabu@hifabu

Uninstall: run this in a terminal:

claude plugin uninstall hifabu@hifabu

更新：在终端里运行上面第一行，先刷新市场，再更新插件。卸载：在终端里运行上面第二行。
