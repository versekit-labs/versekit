Hifabu plugin for Claude Code

Hand a finished video to your publishing computer, from Claude Code.

If you make your videos with Claude Code, the Hifabu plugin lets you send a finished one to the computer that publishes, by asking for it in the same session. Nothing is published until you confirm it on the publishing computer.

如果你用 Claude Code 做视频，装上 Hifabu 插件后，在同一个会话里说一句话，就能把做好的一期交给负责发布的那台电脑。在发布机上确认之前，什么都不会发出去。

Install

  1. Ask Claude Code

    Say this in Claude Code:

    Install the Hifabu plugin from hifabu.com/plugin
    帮我安装 hifabu.com/plugin 的插件

    Claude reads the installation notes at hifabu.com/plugin/install.txt, shows you the command and what it installs, and runs it after you agree.

  2. Or paste one line in a terminal

    claude plugin install hifabu --marketplace https://hifabu.com/plugin/marketplace.json

Either way, run /reload-plugins in Claude Code afterwards, or start a new session.

两种方式选一种。在 Claude Code 里说「帮我安装 hifabu.com/plugin 的插件」：Claude 会读 install.txt，先把命令和它会装什么给你看，你同意后再执行。或者在终端粘贴上面那一行。装好后在 Claude Code 里运行 /reload-plugins，或者重开一个会话。

For AI assistants

The full installation notes are in plain text at hifabu.com/plugin/install.txt. In short:

claude plugin install hifabu --marketplace https://hifabu.com/plugin/marketplace.json

What it does: Adds the Hifabu plugin marketplace from hifabu.com to Claude Code. Installs one plugin, "hifabu": one skill (handoff) and a small command-line program named hifabu. Claude Code checks the plugin archive against this SHA-256 before installing: {{zip_sha256}} {{zip_name}}. No hooks, no MCP server, no background service, no shell script piped from the web. The plugin connects only to hifabu.com, and only uploads files the user asks it to hand over. It never publishes anything.

Expected flow: The assistant shows the user the command above and the points under "What it does", and runs it after the user agrees. Claude Code also asks for permission before it runs the command. After it finishes, the plugin is loaded by running /reload-plugins in Claude Code, or by starting a new session.

Before you start

  • Claude Code on the computer where you make your videos.
  • A publishing computer with Hifabu installed. It can be a second computer.
  • A Hifabu account. If you do not have one, the plugin walks you through signing in the first time you use it.

开始之前需要：做视频的电脑上有 Claude Code；有一台装了 Hifabu 的发布机，可以是另一台电脑；有 Hifabu 账号，没有的话第一次用时插件会带你登录。

Your first handoff

Open Claude Code in your video project and ask for the episode you want to hand over. For episode 17, either of these works:

Hand episode 17 to the publishing computer
把 17 期交给发布机

The first time, some of these steps come up. Each happens once.

  1. Find the episode

    In a project it has not seen before, Claude looks at the folder, works out where the videos, covers and copy are, and asks you to confirm in a sentence or two. It saves this in .hifabu/project.json in the project, so next time it does not ask.

    第一次在一个项目里用：Claude 看一遍项目目录，找出成片、封面和文案在哪，用一两句话请你确认，然后记在项目里的 .hifabu/project.json，下次不再问。

  2. Sign in to Hifabu

    Your browser opens hifabu.com. Sign in, check that the 6-digit code matches the one shown in Claude Code, and allow this computer.

    浏览器打开 hifabu.com：登录，核对页面上的 6 位码和 Claude Code 里显示的一致，点允许。

  3. Turn on transfer between your computers

    Open My Hifabu (「我的 Hifabu」) on hifabu.com and choose 「申请开通」 (request transfer). We turn it on by hand, usually within one working day, and My Hifabu shows it once it is on. Claude remembers the episode and carries on when you ask again.

    到 hifabu.com 的「我的 Hifabu」点「申请开通」，两台电脑之间才能传片。由我们人工开通，通常一个工作日内，开通后会在「我的 Hifabu」里显示。Claude 会记住这一期，开通后再说一声就接着交。

  4. Choose an account group

    Claude lists the account groups on your publishing computer, with the platforms in each, and asks which one to use for this project. It remembers your choice. To use another group once, say so: "hand this one to the 中医 group".

    Claude 列出发布机上的账号组和各组的平台，问这个项目交到哪个组，之后记住。某一期想换组，直接说「这期交到中医组」。

  5. It is handed over

    You get a delivery number right away, and the upload carries on in the background, even if you close Claude Code. Ask 「到了吗」 ("has it arrived?") in the same session to see where it is.

    马上拿到投递号，上传在后台进行，关掉 Claude Code 也会继续。在同一个会话里问「到了吗」，就能看到到哪一步了。

  6. Confirm on the publishing computer

    When it arrives, each platform gets a draft that waits for you. Confirm them on the publishing computer's Today page or in Feishu. Nothing is published before you do.

    到了以后，每个平台一条待确认稿。在发布机的「今天」页或飞书上确认，确认之前不会发出去。

Update

After your first handoff, the plugin updates itself when a new version is out. To update by hand, run this in a terminal. It refreshes the marketplace first, then updates the plugin:

claude plugin marketplace update hifabu && claude plugin update hifabu@hifabu

Then run /reload-plugins in Claude Code.

第一次交过之后，插件有新版本会自己更新。要手动更新，在终端运行上面这一行：先刷新市场，再更新插件。然后在 Claude Code 里运行 /reload-plugins。

Uninstall

  1. Sign out first

    In Claude Code, say 「退出 Hifabu」 ("sign out of Hifabu"). This removes this computer from your Hifabu account and deletes the sign-in from the Keychain.

  2. Remove the plugin

    Run this in a terminal. It also deletes the plugin's folder, including any upload that has not finished.

    claude plugin uninstall hifabu@hifabu

    To remove the Hifabu marketplace as well:

    claude plugin marketplace remove hifabu

  3. If you removed it without signing out

    Open Keychain Access, search for hifabu, and delete what it finds. Then open My Hifabu and remove this computer.

卸载：先在 Claude Code 里说「退出 Hifabu」，这会把这台电脑从你的 Hifabu 账号里移除，并删掉钥匙串里的登录。再在终端运行 claude plugin uninstall hifabu@hifabu，插件目录和没传完的任务会一起删掉；也想去掉 Hifabu 插件市场的话，再运行 claude plugin marketplace remove hifabu。如果没先退出就卸载了：打开「钥匙串访问」，搜索 hifabu，删掉找到的条目，再到「我的 Hifabu」里移除这台电脑。
