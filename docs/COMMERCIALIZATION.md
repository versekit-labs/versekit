# Hifabu 商业化可行性与路径

整理于 2026-11-21，依据所有者与设计会话当天的讨论和公开资料调研。产品名 Hifabu（hifabu.com）取代纪要里的 Castlane 候选；仓库和命令行名暂仍是 VerseKit / `vk`。

这是一份判断记录，不是架构决定。架构以 [BLUEPRINT](BLUEPRINT.md) 和后续 ADR 为准。前一份讨论纪要是 `PRODUCT-DISCUSSION-2026-11-21.md`（在协调器工作区），本文替换其中「商业化判断」一节的结论。

**证据等级**：文中【查到】指有公开来源；【自述】指来自创始人或博客的自报数字，未独立核实；【推断】是我们的判断；【未查到】是没找到资料，不等于不存在。

---

## 1. 结论

1. **自用加开源：可行。** 已在跑，没有收入压力。
2. **国内个人订阅，卖「发布」：不可行。** 蚁小二免费版和 198 元/年个人版、开源项目已经把发布做成近乎免费的商品，且收费会放大法律风险。
3. **国内个人订阅，卖「跨平台复盘」：偏弱。** 被蚁小二个人版自带的数据分析压在下面，又有「导出给 Claude」这个零成本替代。
4. **最有可能成立的收费物是「案例 + 可运行的 skill」**，其次是过审后的海外发布云服务。两者都还没有付费证据。
5. **一个人能做的**：网站、案例和 skill 库、海外官方 API 发布。**一个人做不稳的**：国内多平台浏览器发布的长期维护。后者应保持免费、开源、尽力而为。
6. **最大风险不是技术，是需求从未被验证。** 到 2026-11-21，外部付费用户为零，TikTok 官方应用仍在审核。

## 2. 目标用户

**所有者的描述**：小红书 5k–1 万粉的个人创作者；一个人几个号、每个号几个平台；想同时做海外；缺内容来源，不知道怎么用 AI 做出别人那种优秀视频；没有强烈的赚钱压力。

**我们的修正【推断】**：
- 一人多号、多平台、想做海外，本身就是想赚钱的行为。更准确的画像是「想靠内容赚钱、但还没赚到的副业创作者」。
- 好处：这类人是知识付费的典型买家。坏处：买完做不出结果就流失和差评，这是卖课行业口碑差的根源。
- 一人多号会抬高小红书的风控风险。
- 这一档粉丝量的创作者有多少人【未查到】。

**首批收窄**：已经在用 AI 做内容、不需要被教育的创作者，他们最先付费。

## 3. 价值链与三层判断

用户的路径：**拿到选题 → 学会做出来 → 发到各平台**。

| 层 | 必要性 | 能否收费 | 竞争 |
|---|---|---|---|
| AI 资讯 | 中。只对做 AI 或科技内容的人是选题来源 | 很难 | WaytoAGI 免费，报道约 900 万用户【查到】；AI 日报同质化严重 |
| 案例 + skill | 高。「找不到好的、找到也不会做」是真痛点 | 能，单价低 | 有付费先例，没看到「案例直接可运行」的做法 |
| 多平台发布 | 高，但已是免费商品 | 国内不能，海外云服务可以 | 蚁小二、开源项目、Postiz |

**定位**：看到一个爆款 AI 视频，用现成的 skill 做出自己的版本，一次发到所有平台。资讯只保留「新出的可做案例和工具」，不做泛 AI 新闻。

行业共性抱怨：付费内容里九成网上能免费找到。

### 4.4 海外：Postiz

- 收入：2025-11 约 1.4 万美元 MRR，2026-07 约 14.5 万美元，9 月博客标题称 220 万美元 ARR【自述，数字互相不一致】。
- 增长来源：面向 AI Agent 重新定位，CLI、MCP、API 每档都含；官方定价 29 美元/月起（公开价目为 29、39、49、99 美元）【查到】。
- 付钱的仍是人，买的是托管：已过审的平台应用、基础设施、排期。Agent 是获客渠道，不是收费对象。
- 它不做国内平台，是全球英文市场，且踩中了一次生态爆发，**不能当预期**。

## 5. 平台与法律风险

**TikTok 官方 API**【查到，官方文档】：
- 应用未过 Direct Post audit 时，24 小时内最多 5 个用户能发帖，且帖子只能是私密、仅自己可见。
- 过审后无固定的应用用户数上限；每个创作者账号每 24 小时约 15 条，且所有第三方应用共用这个额度。
- 应用审核和 Direct Post audit 是两道，分别过。官方要求 Direct Post 面向较广泛的原创创作者，纯内部工具不符合。
- **现状**：2026-11-21 所有者确认仍在审核。

**小红书**【查到】：
- 2026-03 公告打击 AI 托管账号：直接通过托管工具注册、发布、互动的账号会封禁；偶发使用先警告限流。报道称处置 42 万个账号（该报道日期与公告时间不一致，需核实）。
- 2026-08 的 AI 治理规则反对云端 AI 工具或手机脚本自动运营账号。
- 没有专门针对「非官方第三方发布工具」的禁令，但自动化行为在规则覆盖范围内。
- 本机浏览器加用户自己登录，解决了 11-14 封号的根因（异地 IP），但不等于没有风险：浏览器自动化的可检测特征【未查到】具体机制。
- 一人多号会抬高风险。

**法律**：微信群控案中，法院认定批量操作软件构成不正当竞争，「技术中立」抗辩未被采纳【查到】。抖音、小红书模拟登录工具的直接判例【未查到】。开源自用阶段风险远，收费并规模化后工具方责任变重。

**产品立场**：国内平台保持「人确认后才发、不做自动互动、不做批量多号」，每个平台在产品里写明风险。

## 6. 产品形态

| 部分 | 形态 | 收费 |
|---|---|---|
| 案例库、skill 库、会员 | 网站 | 是 |
| 海外官方 API 发布 | 网站，过审后可云端代发 | 是，美元订阅 |
| 国内平台发布 | 本地程序，用户本机浏览器 | 否，开源免费，不承诺稳定 |
| 桌面客户端 | 薄壳包住现有 Node 服务和本地网页 | 阶段 0、1 不做 |

**桌面客户端的触发条件**：有付费用户明确因为「装不上」而用不了国内发布。到时用 Electron 薄壳，不重写；需确认内置 Node 版本不低于 22.13。

**待验证**：国内创作者多用 Windows，现有安装脚本只支持 macOS 和 Linux，Windows 上的服务管理、浏览器接管、登录态隔离都没验证过。如果目标人群 Windows 占多数，浏览器扩展值得评估一次（跨系统、环境真实，但浏览器关了就不能定时发）。

**云后台**：所有者明确可以做，只要商业模式成立。云端代发只对走官方 API 的平台成立；国内平台靠本机登录态，云端代发会回到异地 IP 问题。

| 平台 | 状态（2026-11-21） | 备注 |
|---|---|---|

| B 站 | 适配器已有，待所有者真机试 | biliup 加自己的 cookie |
| TikTok 网页版 | 适配器已有，待真机 | 不依赖官方 API 审核 |

| 抖音 | 未建，#276 | 参考 social-auto-upload，自写 CDP，先做存草稿 |

## 8. 商业化路径

| 阶段 | 做什么 | 收什么钱 | 过关标准 |
|---|---|---|---|
| 0，约四周 | 不写代码。发 10 期「案例拆解 + skill」 | 不收 | 有人主动来要 skill，且有人真做出了视频 |
| 1 | 会员：完整 skill 库、每周新案例、配套发布工具 | 199–399 元/年 | 100 个付费，次月仍在用 |
| 2 | 云端代跑；TikTok 过审后加海外发布云服务 | 按量积分或美元订阅 | 单用户月消费明显高于会员费 |
| 3 | 多用户 SaaS | 订阅 | 按既定规则，等第 3 个用户再做 |

**收入量级【推断】**：199 元/年乘 1000 人约 20 万元/年，是副业规模。要做到月入 1 万美元，按 198 元/年需要约 4300 个付费用户，按 29 美元/月只需约 350 个。

**案例内容的版权口径**：不下载再分发他人视频，只做链接或嵌入加拆解；他人 skill 看许可证，无许可证的自己重写。

**资讯层的变现参照**【自述，样本少】：头部靠广告，小号靠 AI 工具联盟佣金，有人称 1200 订阅月入约 4200 美元。国内 AI 工具联盟佣金体系是否成熟【未查到】。

## 9. 一个人做得到什么

| 部分 | 一个人能否做到商业水准 | 原因 |
|---|---|---|
| 网站、案例库、skill 库 | 能 | 内容型，可靠性要求低 |
| 海外官方 API 发布 | 能 | 接口稳定有文档 |
| 国内浏览器发布 | 不能 | 页面随时改版，需持续跟修；真机验证只能所有者做；还要乘上 Windows 和 macOS |
| 云端代跑视频 | 勉强 | 有成本、排队、失败退款等运营负担 |

真正的瓶颈不是写代码（协调器加 worker 的流程已在跑），而是只有所有者能做的三件事：每周把案例还原成可用 skill 并长期坚持；获客；真机验证和客服。获客取决于所有者现有受众，这一点本次未了解，对成败的影响大于产品质量。

## 10. 止损线

继续按现有路线做，最可能的结局是做出一个质量很好但没人付费的工具。为防止「一直建设、不去验证」：

1. **冻结新工程**：桌面客户端、改名迁移、多用户、SaaS，直到有付费用户。发布适配器（#274–#276）属于「跑通发布」，在范围内。
2. **时间盒**：六到八周，完成阶段 0 的 10 期内容。
3. **通过标准（建议，所有者定数字）**：至少 30 人主动索取 skill，至少 5 人做出视频。
4. **不通过就降级**：当作自用工具和开源作品继续维护，不再按生意投入。

## 11. 待所有者决定

1. 止损线的具体数字，以及每周能投入的时间。
2. 现有各平台账号的粉丝量，用来估计首批冷启动的触达。
3. 阶段 0 选哪 10 个案例、每期的格式。
4. TikTok 过审后，是否把「云端只经手授权令牌、不经手原片」的海外发布服务列为阶段 2 的首个收费物。
5. YouTube 是否现在就提交 Google API 合规审核。

## 12. 没查到的

- 易媒助手价格；蚁小二用户数和营收。
- 抖音开放平台对个人开发者的发布权限条件（TikTok 和抖音是两套）。
- 国内个人创作者付费意愿的权威数据；小红书 5k–1 万粉段位的人数。
- 小红书具体检测浏览器自动化的机制，以及封号阈值。
- 国内 AI 联盟佣金的行情。
- YouTube Data API 每日配额的现行数字（移植时再查）。
- 视频号登录实际能撑多久。
