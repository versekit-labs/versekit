- **volc1 上的中转照常运行，不停、不拆。** 所有者现在每天靠它把视频送到发布机。迁到新云端时新旧并存，新路跑通后再下线，只动 versekit 自己的站点块。

## 五、顺带

- 11-17 记过的不稳定测试还在，而且这次复现了：在本 PR 的分支上跑全量 `npm test`，`packages/driver-browser/test/isolation.test.mjs` 里「chromeUserDataDirOnPort 能读出监听端口上 Chrome 的 --user-data-dir」和「ACC-acct-iso-01：B 的标记指向 A 的 Chrome 的端口…」两项失败；单独跑这个文件两次都全过。本 PR 没有改 `packages/`。多半是全量并行时端口或 Chrome 启动抢时间。建议开个小单查清楚，否则它会在别的 PR 的 CI 上随机变红。
