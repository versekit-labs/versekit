# 更新记录

## 0.2.2

- 制作机每天检查一次插件市场。有新版本时，在交付或查询回复的末尾提醒，并附上刷新市场和更新插件的命令。
- 查不到版本时只记本地日志，交付流程照常继续。

## 0.2.1

- 单视频项目的路径里能认出期号时，`work.key` 按期号定；项目加入更多期后，已交作品的 key 保持不变。
- 认不出期号的单视频项目，仍用经用户确认的作品名。

## 0.2.0

- 在项目内保存扫描并确认的素材约定，以稳定标识关联期号和账号组。
- 使用制作机小程序预览 v1 交付清单、提交后台投递并查询进度。
- 首次使用时通过 Claude Code 权限确认开启 Hifabu 市场自动更新。
- 安装包只含小程序、运行时安装器、交付技能、参考和说明。

## 0.1.0

- 提供 `/hifabu:handoff`，从制作会话提交成片、封面和发布文案，并查询投递进度。
