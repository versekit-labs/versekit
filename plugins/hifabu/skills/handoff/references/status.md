# 查询投递

用本会话已登记的投递号或用户提供的投递号跑 `delivery show <投递号>`。没有时用 `delivery list` 按选题或期号匹配。多个都符合则列出选项请用户选，随后查明细。

| CLI 状态 | 对用户报告 |
| --- | --- |
| `pending`、`queued` | 按返回内容说明刚登记或正排队，后台会继续。断网时带上已传大小。 |
| `uploading` | 正在传。带上已传与总字节数、预计时间。 |
| `waiting` | 等发布机来取。带上最近领取时间，超过 6 小时就请用户到另一台电脑打开 Hifabu。 |
| `downloading` | 发布机在下载，沿用进度信息。 |
| `awaiting_confirmation` | 等你确认。列出返回的平台稿、账号、建议时间和未接收的平台及原因。确认在发布机「今天」页或飞书。 |
| `failed` | 没交成。给出该次的原因和下一步，参见 [errors.md](errors.md)。 |

以结果的 `message`、进度和回报为准。展示投递号。制作机查询到的终点是「等你确认」。
