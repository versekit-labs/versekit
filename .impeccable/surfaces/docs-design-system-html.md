# 系统

**模式**：Operate。只按桌面宽度设计，窄屏不坏即可。
**为谁**：登录到这个服务的每一个用户。首先是所有者自己；其次是被邀请来的创作者，她不懂命令行，也不该需要懂。
**解决什么**：把账号、设备接上并保持可用；出了问题或想改发布习惯时来这里。平时不用看。
**v3（2026-11-18，所有者定）整页重排**。旧的任务书内容作废，以这一份为准。所有者的要求：界面上不出现命令；升级、登录平台账号都在界面上做；发布机的出口 IP 和所在国家城市要看得到。

**页面职责：一页三件事（所有者多一件），用页内分段分开，一次只看一件**
1. **账号**（默认）：账号组、平台账号、登录。最常来的原因是「某个号要重新登录」。
2. **发布方案**：哪种成片发到哪些平台、按什么节奏；平台规则（不能关）。
3. **设备**：发布机（在不在线、出口位置、版本、更新）、Claude（哪台电脑在往这里送作品）。
4. **通知**（2026-11-18 补，所有者指出原来没有地方关联飞书）：接自己的飞书。没接、等你扫码、差一步（让卡片上的按钮能点）、接好了、卡片发不出去、不用飞书，六种状态各有一句话和至多一个按钮；接好后能选往飞书发哪几类、发测试卡片、断开。全程扫码，不填凭证。不接也能用，确认只在网页上。
5. **用户**：只有服务的所有者看得到。邀请（填邮箱）、看每个用户的状态、设备数和用了多少空间、停用和重新启用。没有任何入口能看别人的作品。
「最近出的问题」在分段上面，只在有问题时出现，每个分段都看得到。

**对象模型**
- 平台账号绑定一台发布机。只有一台发布机时不出现「发布机」一列。
- 设备两种：发布机、Claude。都通过「在那台电脑上发起、在网页上点允许」接入，不填任何码。
- 出口位置是发布机的属性；「平时在哪」是账号的属性（上次登录成功时的位置）。

**登录平台账号（全在网页上）**
- 点「登录」，在这一行下面展开：左边是二维码（由发布机取回来显示在这里），右边一句「用小红书 App 扫这个码」和状态。状态自己走：等你扫码 → 已扫码，在手机上点确认 → 登录好了（这一行收起）。不需要人点「我登录好了」。
- 展开条里两个次要入口：「改用短信验证码」（就地换成手机号 + 验证码两步）、「在发布机上打开登录窗口」（给扫码和短信都不行的平台；这时才有「我登录好了」）。
- 官方接口的平台是「授权」：点了在新标签页打开平台的授权页，回来自动变成正常。
- 登录前的说明、退出登录的确认、登录到了别的号、TikTok 应用凭证：沿用 2026-11-17 定的行内展开和轻重规则（正常 → 文字链接；要处理 → 描边；进行中的下一步 → 墨色实心，全页同时只有一个）。
- 二维码过期：原地显示「二维码过期了」+「换一个」。发布机不在线：登录按钮不可用，并说「发布机不在线，登录要它在线」。

**设备**
- 发布机每台一行：名字、在线与否、出口位置（国家 城市 + IP；国内和海外两条线路不一样时两行都写）、线路类型（家庭宽带 / 机房线路）、绑了几个账号、版本。
- 版本列：已是最新 → 灰字；有新版本 → 描边「现在更新」；正在更新 → 「正在更新…」不可点；太旧 → 红「要更新才能继续发」+ 描边「现在更新」。自动更新是每台一个开关。
- 出口位置变了（和绑定账号平时的位置不在同一个国家）：这一行黄点「出口位置变了」，行下展开说明哪几个账号暂停了，两个按钮：「继续用新位置」「我去关掉代理」。
- 「接一台发布机」：展开两步——打开官网的安装页照着装（界面里只有「打开安装页」和「复制安装页的地址」，不出现命令）；装完它会自己打开浏览器让你点「允许」。这里等着，接上后这一行变成新设备。
- 「接 Claude」：展开一句可以复制的话，发给 Claude，它自己装好并让你点「允许」。
- 断开设备：行内确认；发布机写出「绑在它上面的 N 个账号会发不了」。

**状态词表**（新增的）
- 设备：`在线` 绿 / `不在线 · 3 小时前` 红 / `正在更新…` 灰 / `等你允许` 黄。
- 出口：`美国 洛杉矶`（灰，正常）/ `出口位置变了` 黄 / `查不到位置` 灰。
- 登录进行中：`等你扫码` / `已扫码，在手机上点确认` / `验证码已发到 138****0000` / `二维码过期了`。

**明确不做**：账号组矩阵、日志全文、云端运维、指纹环境和代理配置、团队成员。个人资料、密码、导出和删除数据在侧栏底部的用户菜单里，不在这一页（这一轮只画入口）。
**数据从哪来**：`group.list`、`account.list`、`account.login.*`、`plan.show / set`、`device.list / rename / revoke`、`device.egress`、`update.status / update`、`run.list --failed`。
**依据**：ADR-0005；`docs/design/FLOW-v2.md`。硬规则：没有人确认，一条都不会发；平台登录不离开发布机。
**页面上不出现命令。**

## Direction contract

THESIS：安静的工作台。一屏只回答一个问题，主操作只有一个。参考 Things 3（今天的安静）、Linear（一行一个对象、状态小而清楚）。
OWN-WORLD：暖白场地 #fafaf8、白色面板、发丝线；墨色 #1a1c1f 是唯一的主按钮色；黄只表示"等你处理"，红只表示"出了问题"，绿只表示"正常"。系统字体，表格数字等宽对齐；等宽字只用于 IP 地址和配对码。
FORM：左 208px 侧栏四项 + 右侧单列内容；标题下一排页内分段（账号、发布方案、设备）。只按桌面宽度设计，窄屏不坏即可。
FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and the baseline screenshots in docs/design/screenshots/v3/.
FIRST VIEWPORT：标题 + "一切正常 / 有 N 件事要处理"；分段；账号表。
SIGNATURE：登录就在那一行下面展开，二维码直接在网页里。
