# 总览 · 这段时间整体如何

- **Scope**：`overview.html`，当前账号组的时间范围汇总；`?group=all` 时为跨组只读汇总。
- **Mode**：Operate。
- **Audience**：每周复盘一次的创作者。
- **Job**：回答"这段时间发得怎么样、数据可信吗、哪个平台在拖后腿"。
- **Action**：切时间范围、按平台看、看数据新鲜度。
- **Proof / Content**：成功发布数、播放、互动、覆盖度、各账号采集新鲜度。
- **Constraints**：跨组汇总只读；数字必须带口径。

## Direction contract

**THESIS**：不做"四张大数字卡+一条折线"的通用仪表盘。数字要带口径，可信度与数字同级。

**OWN-WORLD**：灰白场地、白面板、深蓝柱；状态点区分新鲜与过期；零阴影。

**STORY**：先看本周发布与空档 → 看平台拆分 → 看数据新鲜度判断该不该信 → 回到账号或作品。

**FIRST VIEWPORT**：时间范围切换、四个带口径的关键数字、每日发布柱状、平台拆分、数据新鲜度面板。

**FORM**：延续既有面板与列表语言；seed: seed:a61cb2af8194ee80

**FINISH**：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
