# 交给发布机

[任务书与结构](../../docs/design/handoff/BRIEF.md) §1 和 §3 记录了已确认的页面职责、对象模型和状态词表。

- **为谁**：在 Claude Code 里做完成片、要交给另一台发布机的创作者。
- **解决什么**：确认本期素材何时到达发布机，出问题时知道怎么继续。
- **成功长什么样**：一句话交付这期作品，之后能看到到达状态和各平台的建议排期。
- **明确不做**：在制作机上发布、登录平台或改排期。
- **数据从哪来**：原型演示交付及中转状态，实际数据由交付和发布机入库回报提供。
