# Hifabu 发布机下载页（hifabu.com/download）

**模式**：Persuade + Instruct（公开静态说明与安装页）。
**为谁**：
1. 刚注册或准备使用 Hifabu、要把一台电脑设成发布机的创作者（主要读者）：会用 Mac，不一定会用终端。
2. 想先看清「会装什么、常驻什么、怎么验证、怎么卸载」再决定安装的内行读者。

**解决什么**：在一台干净的电脑上装好 Hifabu 发布机，安装前先提醒选对和手机同网络的电脑，透明列出将安装的文件（版本号、体积、来源、目录）、唯一后台服务和卸载方式，并提供一行安装与「先校验再运行」三行命令。

**结构（一页一个任务：装好发布机，9 块内容）**：
1. 标题和一句话：把这台电脑设成 Hifabu 发布机，说明发布机是什么。
2. 放在哪台电脑上（第一块，先于安装）：必须和发布时用的手机在同一个网络（同一宽带），降低异地登录与发布风险。
3. 系统要求：macOS 13.5 或更新（Apple 芯片和 Intel），约 300MB 空间另加视频空间，需常开联网；Linux 可用但非主推；不支持 Windows。
4. 安装：锁定版本的一行命令 + 复制按钮 + 打开终端步骤 + 终端示意图 + 装完后浏览器自动打开控制台并在「系统」页登录 Hifabu 账号。
5. 会装什么：四行表格（Node.js 官方原版、Hifabu 程序、用到才装的 biliup、用到才装的 lark-cli），版本号与体积全部取自发版清单，路径如实写 `~/.versekit` 并注明旧名之后会改。
6. 会在后台常驻什么：1 个后台服务 `com.hifabu.daemon` 的职责、触发周期、日志目录，以及明确不做（不改系统设置、不装浏览器插件、不要管理员密码）。
7. 这个版本：版本号、发布日期、来自 CHANGELOG 的更新说明、`install.sh` 的 SHA-256、`SHA256SUMS` 与源码 tag 链接，以及默认收起的「先校验再运行」三行命令。
8. 怎么卸载：控制台「系统 → 卸载 Hifabu」（默认保留数据，可选连数据一起删）、数据目录位置，以及卸载后到「我的 Hifabu」移除这台机器。
9. 以前的版本：指向 `versions/` 历史版本列表。

**成功长什么样**：
- 读者 3 分钟内只粘贴一次命令即可完成安装并在浏览器看到控制台。
- 版本号、体积、SHA-256 全部从发版清单生成，页面不手写。
- 浅色、深色、手机宽度（390px）均无横向溢出，触控目标合规。
- 「先校验再运行」三行命令可原样跑通。

**明确不做**：
- 不做 Windows 安装指引、不做未签名的 .pkg、测试期不签名公证。
- 这次不搬本机数据目录（如实标注旧路径）。
- 下载不要求登录；不在页面上替用户自动执行命令。
- 插件页不反向链回本页。

**数据从哪来**：由发布脚本 `deploy/hifabu/publish-release.mjs` 在发版构建与激活时读取 `manifest.json` 和 `install.sh` 实际 SHA-256，调用 `site/download/render.mjs` 渲染静态 HTML，不在浏览器运行时请求清单。

## Direction contract

THESIS：冷静、透明的公开安装页。先讲清防风控前提和装机清单，再给一行可复制命令，让非技术创作者安心上手、内行能逐项核对。
OWN-WORLD：沿用官网 `site/style.css` 的双色主题（浅色 `#fbfaf7` 底 / `#1d1d1b` 墨 / `#d9622b` 强调色；深色 `#161614` 底 / `#ecebe6` 字），单栏 `720px` 阅读宽度，中英双语（英文正文配 `.zh` 中文段），页头页脚与官网首页、隐私政策、服务条款保持一致。
FORM：单列文档流，第一块用醒目边框提示「与手机同网络」，安装命令使用 `.cmd` 复制条配终端示意图，组件清使用可横向滚动的轻量表格，「先校验再运行」放进默认收起的 `<details>`。
FINISH：通过假清单生成页面，在浅色、深色、390px 手机宽下截图核对并提交至 `docs/design/screenshots/download/`，通过 `impeccable detect` 与 `npm run ci`。
FIRST VIEWPORT：站点页头、标题与定位说明、「放在哪台电脑上」同网络提示。
SIGNATURE：每项体积、版本号、SHA-256 都可追溯到发版清单，且三行校验命令直接可跑。
